# 详细设计文档

本目录是微服务电商平台的详细设计文档集。阅读顺序建议：先读**通用约定**（所有文档的强制基线），再按服务阅读，最后读**平台与部署**了解横切设计。

| 序号 | 文档 | 内容概要 | 对应需求 |
|---|---|---|---|
| 00 | [通用设计约定](00-通用约定.md) | 命名规范、统一响应格式、错误码号段、认证授权、幂等、金额与时间表示、数据库与缓存约定、事件信封与标准事件目录、服务间调用、日志脱敏、配置管理、代码目录结构、文档模板 | 全局 |
| 01 | [用户服务](01-用户服务.md) | 注册登录、令牌与刷新轮换、密码找回、资料与收货地址、RBAC 角色权限、账号管理、OAuth | FR-US-001~010 |
| 02 | [商品目录服务](02-商品目录服务.md) | 分类树、SPU/SKU、商品发布与上下架、列表与搜索、库存三段式预占与扣减、库存流水、评价、标签 | FR-CAT-001~014 |
| 03 | [购物车服务](03-购物车服务.md) | 加购与改量、选中结算、失效商品处理、游客车合并、价格实时校验、Redis 主存储与异步落库 | FR-CART-001~009 |
| 04 | [订单服务](04-订单服务.md) | 下单 Saga、订单状态机、超时关闭与支付竞态、发货、确认收货、退款申请、改价、导出、异常订单 | FR-ORD-001~014 |
| 05 | [支付服务](05-支付服务.md) | 发起支付、Stripe/PayPal 对接、回调验签与幂等、回调丢失补偿、退款、交易流水、对账、PCI 边界 | FR-PAY-001~010 |
| 06 | [通知服务](06-通知服务.md) | 事件消费、模板与版本管理、邮件短信渠道适配、重试与死信、用户偏好、发送记录、验证码同步链路 | FR-NOT-001~009 |
| 07 | [平台与部署](07-平台与部署.md) | 端到端时序、网关中间件链与限流熔断、服务发现与健康检查、可观测性与告警、容器与 K8s 编排、CI/CD、横切关注点、安全加固、测试策略 | FR-PLT-001~009 |
